# Diseno

## Principios

- Claridad antes que decoracion.
- Informacion densa pero respirable.
- Estados visibles con color, texto y jerarquia.
- Acciones principales siempre cerca del contexto.
- Formularios cortos, con validaciones claras.
- Tablas pensadas para escanear, filtrar y comparar.

## Tono visual

La app debe sentirse operativa, seria y rapida. No debe parecer una landing comercial. La pantalla principal debe mostrar trabajo real: viajes, vehiculos, estados, fechas, importes, alertas y acciones.

## Reglas de estilo

- Usar fondos neutros y superficies blancas.
- Reservar colores intensos para estados, alertas y acciones.
- Mantener bordes suaves: radio maximo recomendado de 8px.
- Evitar sombras pesadas; preferir bordes y contraste.
- Usar tipografia sans serif del sistema.
- No depender solo del color para comunicar estado.
- Mantener botones con alto minimo de 36px.
- Mantener tablas con encabezados fijos o muy claros cuando crezcan.

## Layout base

- Barra lateral compacta para navegacion principal.
- Encabezado superior con fecha, busqueda y acciones globales.
- Area central con tablero, filtros y tabla/listado.
- Panel lateral o modal para detalle de viaje.
