# Componentes iniciales

## Navegacion

- App shell con barra lateral.
- Items: Tablero, Viajes, Clientes, Choferes, Camiones, Reportes.

## Datos

- Tabla de viajes.
- Filtros por fecha, estado, cliente, chofer, camion, semi y lugar.
- Busqueda rapida.
- Tarjetas de resumen operativo.

## Formularios

- Alta/edicion de viaje.
- Alta/edicion de clientes, cargas, lugares, choferes, camiones y semis.
- Cambio de estado.
- Carga de documentacion.
- Registro de observaciones.

## Estados visuales

Cada estado debe tener:

- Etiqueta textual.
- Color de apoyo.
- Prioridad visual.
- Descripcion operativa breve.

## Acciones frecuentes

- Nuevo viaje.
- Cambiar estado.
- Ver detalle.
- Adjuntar documento.
- Marcar observado.
- Finalizar operacion.
