# Componentes iniciales

## Navegacion

- App shell con barra lateral.
- Items: Tablero, Camiones, Turnos, Documentacion, Reportes, Configuracion.

## Datos

- Tabla de camiones.
- Filtros por fecha, estado, proveedor, patente y tipo de operacion.
- Busqueda rapida.
- Tarjetas de resumen operativo.

## Formularios

- Alta/edicion de camion.
- Cambio de estado.
- Carga de documentacion.
- Registro de observaciones.

## Estados visuales

Cada estado debe tener:

- Etiqueta textual.
- Color de apoyo.
- Prioridad visual.
- Descripcion operativa breve.

## Acciones frecuentes

- Nuevo camion.
- Cambiar estado.
- Ver detalle.
- Adjuntar documento.
- Marcar observado.
- Finalizar operacion.
